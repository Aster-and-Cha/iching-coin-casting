易経・擲銭法 計算アプリ
========================

■ 起動方法
1. このフォルダーにある index.html をダブルクリックします。
2. Windows の Microsoft Edge、Google Chrome などのブラウザーで開きます。
   インストールやインターネット接続は不要です。

■ GitHub Pages / iPhone
公開後は HTTPS のURLを開けば、Safariなどで利用できます。初回アクセス時はインターネット接続が必要です。
Safariでは共有メニューから「ホーム画面に追加」を選ぶと、ホーム画面のアイコンから起動できます。
初回表示後にService Workerがアプリ本体・manifest・アイコンをキャッシュすると、オフラインでも起動して計算できます。
初回アクセス中に接続が切れた場合、キャッシュがまだないためオフライン起動できません。更新時に新しいファイル一式を取得できなければ、更新は有効にならず、キャッシュ済みの旧版が引き続き使われます。
入力した数字や計算結果を送信・保存する機能はありません。

GitHub Pagesの公開元はリポジトリの「Settings」→「Pages」で、mainブランチのルート（/(root)）を選びます。
サイトのURLは https://<GitHubユーザー名>.github.io/iching-coin-casting/ です。
公開されたサイトとリポジトリの内容は一般公開されます。参考資料の画像や個人的な解説資料は公開対象に含めないでください。

キャッシュ対象を変える更新時は、service-worker.js の CACHE_NAME の末尾の版番号を上げてください。
次回オンライン時に新しいキャッシュへ切り替わり、古い同アプリ用キャッシュは削除されます。

■ 使い方
1. コイン3枚を投げて得た合計値を、1爻から6爻まで選びます。
   1爻が最下段、6爻が最上段です。
2. 6つすべて選ぶと、本卦・動爻・之卦が自動で表示されます。
3. 「入力をクリア」で入力を消して、最初からやり直せます。

入力内容を保存したり、外部へ送信したりする機能はありません。計算はこのHTMLファイル内で行います。

■ 計算ロジック
・6と8を陰爻、7と9を陽爻として、1〜3爻を下卦、4〜6爻を上卦にします。
・各卦の爻は、下から上の順で判定します。
・指定された八卦と六十四卦の対応表を使います。六十四卦表は行を下卦、列を上卦として参照します。
・6と9を動爻として記録し、6は陰から陽へ、9は陽から陰へ反転させて之卦を求めます。
・卦名は番号に対応する名称データから表示し、上卦・下卦名と象徴、番号、爻の図も表示します。

■ 動作確認
アプリ内の計算関数に指定の入力を与えて照合しました。

テスト1
入力（1爻から）：7, 8, 7, 8, 7, 8
結果：本卦63（水火既済）、上卦は坎（水）、下卦は離（火）、動爻なし
表示：動爻なし。之卦なし。之卦の欄は表示しない
判定：本卦・上下卦・動爻が期待結果と一致

テスト2
入力（1爻から）：7, 6, 7, 8, 9, 8
結果：本卦63（水火既済）、動爻は2爻と5爻、之卦11（地天泰）、上卦は坤（地）、下卦は乾（天）
判定：期待結果と一致

追加確認
八卦の上下の全64組み合わせを対応表と照合し、番号と卦名がすべて揃っていることを確認
判定：64通りすべて一致
